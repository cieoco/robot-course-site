## 這堂課要完成什麼？

用自然語言產生可檢查的 PROG JSON，再由你確認後送到控制板。這是選用的進階入口；第一次控制馬達仍建議先完成搖桿與 Blockly 課程。

> **AI 不會取代安全檢查。** 先讓機構保留活動空間，從一顆馬達、30% 動力、短時間動作開始。每次執行前都檢查 JSON 和緊急停止的位置。

## 01　先了解兩種模式

從主選單點「🤖 AI 生成程式」。未設定 AI 服務時，頁面可使用 Mock（離線）預覽；要真正由 AI 產生程式，需在同一網路準備好 `ai-relay` 服務與 Azure OpenAI 設定。

<figure class="lesson-shot"><img src="assets/controller-ai.png" alt="AI 生成程式頁，含 Azure OpenAI 設定、自然語言需求輸入欄與 PROG JSON 區。"><figcaption>實際 AI 程式頁。輸入需求後，先看 JSON，再決定是否執行。</figcaption></figure>

| 模式 | 適合用途 |
| --- | --- |
| Mock（離線） | 認識流程、練習描述需求，不會呼叫外部 AI。 |
| Azure OpenAI | 已完成 relay 設定後，將描述轉為可驗證的 JSON。 |

## 02　寫出可驗證的需求

描述要包含「哪一顆馬達、方向、力道、多久、最後停止」。例如：`讓馬達 1 前進 2 秒後停止`。產生後先按「驗證」，確認 JSON 合法，再看馬達編號、動力、等待時間和停止指令是否符合預期。

## 03　最後才執行或存檔

確認 WebSocket 已連線後，按「執行到 ESP32」。需要重複使用的程式可存入 ESP32；只有已在實機安全驗證過的程式，才開啟「開機自動執行」。

**成功訊號**：你能看懂一份 AI 產生的動作，並在執行前發現錯的馬達編號、方向或時間。
