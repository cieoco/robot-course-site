## 這堂課要完成什麼？

在第一次讓馬達動之前，先用控制板內建的接線圖確認電源、馬達與舵機的位置。這一頁是接線時的查詢工具；不確定時先回來核對，別靠記憶接線。

> **先斷開馬達外接電源再插拔。** ESP32 的 USB 只供應控制板；馬達與舵機需要依機構準備外接電源，而且外接電源 GND 必須和 ESP32 GND 共地。

## 01　從主選單開啟接線說明

連上控制板熱點並開啟 `http://192.168.4.1` 後，點「🔌 接線說明」。頁面會顯示控制板圖、伺服通道、M3／M4 編碼器與可用 GPIO。

## 02　先確認三件事

| 要確認的事 | 為什麼 |
| --- | --- |
| 馬達插在哪個 M1–M4 | 後續搖桿與積木都要選相同編號。 |
| 舵機接 S1 或 S2 | S1、S2 是 0–180° 的指定位置控制。 |
| 外接電源與 ESP32 是否共地 | 沒共地時，常見現象是抖動、重啟或控制無反應。 |

M3、M4 才有編碼器接線與角度控制；M1、M2 只做一般動力控制。沒有接的元件不要在自檢頁勾選。

## 03　接好後立刻自檢

接線完成後不要直接寫積木程式。先開啟「硬體功能檢測」，只勾選目前真的接上的元件，確認正轉、停止與反轉都正確。

**成功訊號**：你說得出每個元件的通道編號，外接電源與共地已確認，而且準備進入自檢。

## 卡住時

| 現象 | 先查什麼 |
| --- | --- |
| 馬達一動就重啟 | 外接電源電流是否足夠、GND 是否共地。 |
| M3／M4 會轉但沒有角度讀值 | 編碼器線、供電與編碼器通道。 |
| 方向和預期相反 | 先在控制頁改反向；確定機構需求後再處理馬達線序。 |
