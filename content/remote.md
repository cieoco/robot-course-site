## 這堂課要完成什麼？

用手機遙控頁面，第一次讓手指的動作直接變成馬達的動作。這不是程式設計；它是最快確認「控制板聽得懂我」的方法。

> **開始前**：先完成硬體功能檢測，讓輪子架空或保留足夠活動空間。第一次只控制一顆馬達，從低出力開始。手不要靠近正在轉的輪軸、齒輪或線材。

## 01　先找到緊急停止

手機連到 ESP32 熱點後，開啟 `http://192.168.4.1`，從主選單進入「🕹️ 搖桿」。頁面右上角有紅色「**緊急停止**」按鈕。

在讓任何東西動起來之前，先按一次，確認你知道它的位置。發生卡住、方向不對、線材被捲入，或你不確定下一步時，先按這顆按鈕；不要用手抓馬達。

按下緊急停止後，將 M3／M4 的滑桿回到 0，並讓對應的圓形按鈕回到 OFF，才重新開始控制。

## 02　用動力滑桿控制 M3

在「⚙️ 馬達控制設定」中找到 **M3 控制**。預設應在「動力」模式，滑桿標示為 `PWM (-100~100)`。

1. 先把 M3 滑桿設為 `20` 或 `30`。
2. 按下上方寫著「控制 M3 馬達」的圓形按鈕，看到 `ON` 才代表開始送動作。
3. 慢慢移動滑桿：正數是正轉，負數是反轉，0 是停止。
4. 完成後再按一次圓形按鈕，讓它回到 `OFF`。

**成功訊號**：你手指改變滑桿數值，M3 依序正轉、停止、反轉；按鈕回到 OFF 後馬達停止。

| 操作 | 送出的意思 |
| --- | --- |
| `+30` | M3 以 30% PWM 出力正轉 |
| `0` | 停止 M3 |
| `-30` | M3 以 30% PWM 出力反轉 |

M4 的操作完全相同，只是使用另一側的 M4 滑桿與按鈕。

## 03　切換到角度模式（只限 M3／M4）

M3、M4 有編碼器，所以除了動力模式，還有「角度」模式。點選 M3 控制卡上的「**角度**」，滑桿會變成 `相對角度 (-180~180)`。

1. 先按「重設零點（目前位置 = 0°）」。
2. 把角度滑桿設為 `30°`，再按 M3 的圓形按鈕切成 ON。
3. 馬達轉動到相對目標後會停住；完成後按 OFF 或緊急停止解除。

這裡的 30° 是「從目前位置再轉 30°」，不是全域的絕對位置。M1、M2 沒有編碼器，因此不提供角度模式；這是正常限制。

若想看角度是否真的被讀到，可展開下方「🔍 編碼器實測（校正用）」區塊，勾選 M3 並按「讀一次」，或開啟輪詢。你會看到 ticks 與角度讀值。

**成功訊號**：角度模式下，M3／M4 轉到設定方向後停止；讀值區不再是 `—`，而是出現數字。

## 04　舵機與搖桿

遙控頁上方有 S1、S2 舵機滑桿，範圍是 0–180°。拖動滑桿就會直接指定舵機位置；先從 90° 附近小幅移動，避免機構撞到極限。

頁面下方的虛擬搖桿可同時控制多顆馬達。第一次操作先使用 M3／M4 的單獨滑桿，因為它能清楚對照「一個滑桿 → 一顆馬達」。

## 卡住時，從這裡查

| 現象 | 先做什麼 |
| --- | --- |
| 拖滑桿沒有動作 | 先確認 M3／M4 圓形按鈕是 ON；只有 ON 時改變滑桿才會送出 PWM。 |
| ON 了還是不動 | 確認手機仍在 ESP32 Wi-Fi，檢查馬達外接電源與共地，再回硬體功能檢測頁。 |
| 按緊急停止後無法再控制 | 將兩個滑桿回到 0、兩個圓形按鈕回到 OFF，再重新啟動一顆馬達。 |
| 角度模式沒有讀值 | 只測 M3／M4；確認編碼器接線、供電與共地，並用「讀一次」確認。 |
| 到位後有輕微抖動 | 這是角度保持嘗試修正位置時可能出現的現象；先按 OFF 或緊急停止解除。 |

## 完成了嗎？

- [ ] 我知道緊急停止在哪裡，並知道要讓滑桿歸零、按鈕 OFF。
- [ ] 我讓 M3 或 M4 正轉、停止、反轉。
- [ ] 我知道圓形按鈕顯示 ON 才會啟動該馬達。
- [ ] 我知道角度模式只適用於 M3、M4。
