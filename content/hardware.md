## 這堂課要完成什麼？

把已接好的元件逐項跑過一次，先把「接線或硬體問題」和「程式問題」分開。只要這一步完成，之後積木程式沒有動作時，排查就會容易很多。

> **開始前**：輪子要架空或保留活動空間；第一次測試請站在能立刻按停止的位置。沒有接的元件必須取消勾選。

## 01　進入硬體功能檢測

從主選單點「🔧 硬體功能檢測」，先看右上方狀態是否為 WebSocket 已連線。若顯示紅色未連線，先回到「手機連上它」確認仍在 ESP32 熱點。

## 02　只勾選目前有接的項目

1. 沒接的馬達、舵機或感測器，取消勾選。
2. 只接一顆馬達時，只保留該馬達。
3. 按「開始勾選檢測」，不要用「開始全部檢測」去測未接的元件。
4. 每一項動作完成後，依眼前看到的結果回答正常或有問題。

| 項目 | 觀察重點 |
| --- | --- |
| M1／M2 | 正轉、停止、反轉都明確。 |
| M3／M4 | 除了馬達動作，編碼器計數也要隨轉動改變。 |
| S1／S2 | 依序掃過角度，機構沒有撞到極限。 |
| 感測器 | 讀值會隨按壓、距離或輸入改變。 |

## 03　遇到紅燈先停在這裡

不要在有錯誤時繼續進到搖桿或積木。記下是哪個項目，回接線頁檢查通道、電源與共地後再測。

**成功訊號**：所有已接元件都通過；M3／M4 的計數不是固定的零值。

## 卡住時

| 現象 | 先做什麼 |
| --- | --- |
| WebSocket 未連線 | 手機重新連到 ESP32 熱點，保留在此 Wi-Fi。 |
| 馬達不動 | 檢查外接電源、共地與馬達插槽。 |
| 方向兩次都一樣 | 檢查接線與方向設定。 |
| 馬達轉、計數不變 | 檢查 M3／M4 編碼器接線與供電。 |
